安装与使用说明

Clash Verge 订阅

本包直接使用 Clash Verge Rev，无需把订阅转换给另一个客户端。打开应用的“订阅”页面，粘贴你自己的订阅地址并导入，选择配置和节点后开启系统代理。订阅有效性和可用节点由你的服务商决定。

Codex 桌面版

这是真实的官方 Codex.app，不是终端版，也不是网页快捷方式。版本为 26.623.141536。主程序、桌面核心框架和内置 Codex 核心的最低系统要求均不高于 macOS 12。

部分附加组件（电脑操作、部分设备与原生集成功能）按 macOS 13 或更新系统构建，因此不保证这些附加功能在 Monterey 可用。已核验文件校验值、Intel 架构和程序元数据；尚未在你的 Mac 上实机启动测试，也未验证旧版的在线登录与服务可用性。

为保留此兼容版本，在 macOS 12 上会关闭该用户的 Codex 自动检查和自动安装更新。更新前请核对新版本的系统要求。

安装位置与已有版本

两个应用安装到“应用程序”文件夹。同名旧应用会保存在 Applications 内名称以 Clash-Codex-Backup 开头的文件夹；你的账号和订阅配置不会被本安装器删除。安装失败时会尝试恢复原应用。

首次打开

自制合并安装包没有 Apple Developer ID Installer 签名。若系统拦截安装包，可在 Finder 中按住 Control 点按安装文件，选择“打开”；如仍被拦截，在“系统偏好设置 → 安全性与隐私 → 通用”选择“仍要打开”。请保留系统安全设置，按系统提示确认。

Clash Verge 的代理服务权限、Codex 登录和 macOS 安全确认需要你本人完成。首次安装不能保证完全没有系统提示。
